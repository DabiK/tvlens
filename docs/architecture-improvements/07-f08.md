# F08 — Un échec transitoire de vision reste définitif

## Contexte

Audit Opus/Astra du code local TV Lens au13octobre2026, incluant les évolutions non publiées. P2 ; Robustesse déduite. Origine : Opus A2.

Une description échoue à cause d’une coupure ou d’un timeout : visionStatus devient error sans reprise dans cette voie, même si le média conservé demeure utilisable.

## Preuves et limites

Politique lue dans le code ; erreurs comptées et visibles, fréquence non mesurée.

Sources à explorer avant modification : `core/session.cjs:318`, `adapters/codex-perception.cjs:74`.

## Direction approuvée

Distinguer les erreurs récupérables et envisager une reprise strictement bornée quand la voie est libre et le média encore présent ; jamais rouvrir une session close ou une archive en lecture seule.

## Critères d’acceptation

- [ ] Classifier erreurs transitoires avec une seule reprise bornée quand la voie est libre et le média existe.
- [ ] Aucun retry d’authentification, confinement refusé, entrée invalide ou erreur définitive.
- [ ] Aucun travail réactivé après ending/closed, dans une archive en lecture seule ou sur média supprimé.
- [ ] Tests fail-once, fail-always, fermeture, média disparu ; compteurs distinguant tentatives/récupération/perte finale.

## Boucle de livraison

1. Session Opus5.5 ultracode fraîche : exploration forcée avec outils de lecture seulement, chaîne d’appels et tests proposés.
2. Implémentation minimale et régression rouge/verte, puis tests hors ligne proportionnés.
3. Reviews indépendantes conformité et architecture, corrections jusqu’à validation.
4. Intégration locale et vérification par la supervision ; sujet suivant ensuite.

## Contraintes

Travaux locaux uniquement pendant l’absence de l’utilisateur : aucun déploiement, push, accès TV/VPS, fournisseur de l’application ou modification d’authentification/données utilisateur. Pas de framework, DB ou modèle nouveau. Conservation jusqu’à suppression, garde de contexte, citations, files bornées, atomicité, idempotence et confinement failclosed restent intacts. Mesures synthétiques identifiées ; aucun gain de latence inventé.
