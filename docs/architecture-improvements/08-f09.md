# F09 — Résumé vivant : plafond de capacité et tentatives identiques

## Contexte

Audit Opus/Astra du code local TV Lens au13octobre2026, incluant les évolutions non publiées. P2 ; Dette de longue session Mac. Origine : Astra A6.

La synthèse réenvoie tous les originaux et dépasse240000caractères. Elle conserve le dernier résumé et affiche une erreur, puis retente une entrée qui ne peut plus diminuer.

## Preuves et limites

Limite déterministe ; aucune durée en heures extrapolée et aucun appel modèle.

Sources à explorer avant modification : `core/living-recap.cjs:87`, `adapters/codex-recap.cjs:41`.

## Direction approuvée

Séparer capacité atteinte et panne transitoire, arrêter les tentatives impossibles. Mesurer ensuite les tailles/corrections avant une synthèse par chapitre avec accès aux originaux et provenance préservée.

## Critères d’acceptation

- [ ] Capacité dépassée est distincte d’une panne transitoire ; ne plus retenter indéfiniment la même entrée au-delà240000caractères.
- [ ] Dernier résumé et provenance restent consultables, état utilisateur explicite et reprise possible quand les conditions changent.
- [ ] Tests limite, signature inchangée/changée et récupération ; aucun appel modèle réel ni synthèse récursive inventée.
- [ ] La synthèse incrémentale par chapitres est hors ce lot : documenter mesures préalables nécessaires.
