## Contexte

Audit Opus/Astra du code local TV Lens au13octobre2026, incluant les évolutions non publiées. P1 ; Défaut fonctionnel. Origine : Astra A2.

Rechercher dans A, ouvrir B qui contient aussi moment-1, puis cliquer une ancienne carte. Le replay reconstruit son identité depuis B. Une réponse tardive peut aussi lire les miniatures du store de B.

## Preuves et limites

Chaîne UI/IPC/replay vérifiée dans le code ; pas de reproduction Electron de cet audit. La carte déjà affichée suffit, sans course ni embeddings.

Sources à explorer avant modification : `app/main.cjs:103`, `app/renderer.js:537`, `app/renderer.js:162`.

## Direction approuvée

Conserver session et génération d’une opération jusqu’au résultat ; invalider/vider les résultats au changement ; refuser un replay ou un rendu appartenant à une autre session.

## Critères d’acceptation

- [ ] Les résultats et miniatures portent la session initiale ; une réponse tardive ne se rend pas dans la nouvelle session.
- [ ] Le reset de session vide/invalide les anciennes cartes ; le replay valide sessionId et passageId.
- [ ] Tests A/B avec le même moment-1, recherche retardée et replay refusé pour la carte ancienne.

## Dépendances
