## Contexte

Audit Opus/Astra du code local TV Lens au13octobre2026, incluant les évolutions non publiées. P2 ; Dette de cycle de vie ; quota déjà corrigé. Origine : Opus A3 + A7.

Une surveillance repart avant la sortie des anciens processus. Sur Mac, un contexte MCP ancien peut encore appeler un inspecteur fermé mais reconnectable ; l’owner de session ne reprend plus nécessairement ce processus.

## Preuves et limites

Chevauchement borné jusqu’à trois secondes établi dans le code ; les constats MCP sont déduits et non reproduits. La limite128 a déjà été remplacée par512 et vérifiée en réel : ce n’est pas un incident encore ouvert.

Sources à explorer avant modification : `adapters/codex-rpc.cjs:39`, `adapters/codex-session-client.cjs:791`, `runtime/surveillance-runtime.cjs:393`, `adapters/video-bridge.cjs:27`.

## Direction approuvée

Attendre une sortie bornée avant reconnexion ; rendre explicites recyclage, fermeture définitive et révocation des contextes en fin de session. Garder un propriétaire du groupe de processus et du nettoyage jusqu’à sa sortie.

## Critères d’acceptation

- [ ] Une reconnexion attend la sortie bornée du groupe précédent ; SIGTERM puis escalade bornée restent limités au groupe possédé.
- [ ] La mort du lanceur ne laisse pas un groupe enfant hors responsabilité ; les échecs de spawn/flux absents sont gérés sans crash global.
- [ ] Fin de session révoque ses contextes MCP ; un appel tardif ne reconnecte pas un rôle sans propriétaire.
- [ ] Tests concurrence close/prepare, rotations, spawn refusé, lanceur mort et contexte révoqué ; auth/confinement inchangés.
