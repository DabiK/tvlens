# LG-07 — Sources et relecture depuis une réponse TV

**Statut :** brouillon, non publié.

## Livrable

Consulter les preuves d’une réponse et revoir le passage cité depuis le companion.

## Bloqué par

LG-05.

## Critères d’acceptation

- [ ] Recherche proactive quand nécessaire ; une relance « lien de l’article » réutilise les sources déjà obtenues.
- [ ] Actions adaptées : source, passage ou approfondissement ; navigation télécommande et retour au programme vérifiés.
- [ ] Une source externe s’affiche dans le companion ou via une fiche/QR clairement indiquée si le navigateur ferait quitter YouTube.
- [ ] Relecture des médias réellement conservés, indication de faible cadence et média expiré ; aucun mouvement interpolé présenté comme observé.
- [ ] Tester sur vidéo réelle une question de contexte puis une demande de source ; vérifier contenu et timestamps, conserver les erreurs.
